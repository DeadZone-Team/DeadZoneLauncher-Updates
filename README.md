# DeadZone Launcher Updates

Official update metadata for DeadZone Minecraft 1.20.1 / Forge 47.3.0.

Launcher clients check `manifest.json` over HTTPS, download only changed assets from release files, and verify each SHA-256 and length before installing. Initial launchers distributed with an empty ManifestUrl require one bootstrap update.

The game files and user account data are stored separately from Launcher binaries. Do not place credentials, private webhooks, or PackGuard shared secrets in this repository.
